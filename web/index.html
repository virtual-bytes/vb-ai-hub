LiteLLM

Totals the work your gateway served from your own hardware. Reads counts from its spend logs; prompts and responses never reach the hub. Use a proxy admin or view-only key, because other keys only see their own requests.

Costs and budgets

Costs are estimates at API prices. On a Claude subscription they show what the same usage would cost on the API, not what you pay.

The hub warns at 80% and 100% of the monthly budget, and once a day past the daily limit, through the webhook in Notifications.

One model per line: model = input, output, cache read, cache write. A name also covers models that start with it, and the longest match wins. Without cache prices, reads cost 10% of input and writes 125%. Check them against Anthropic's pricing page when prices change.

Accounts and access

Connect tools

Connected tools can search your library, read handoffs and manage tasks from inside a session, through MCP. They can add and update tasks, and they can't delete anything.

Track this machine's sessions

Run this on each machine that uses Claude Code. It adds the hooks that send sessions to the hub and brings in the ones already there. First run read -rs HUB_TOKEN && export HUB_TOKEN and paste your access token, so it stays out of your shell history. The command checks the hook it downloads against a checksum.

This hub isn't on https, so the token and your sessions cross the network unencrypted. Put it behind a reverse proxy with TLS before connecting other machines.

Let Claude use the library

Run this once. Claude Code keeps the token in its own settings.

Let Cursor use the library

Add this to ~/.cursor/mcp.json, and set HUB_TOKEN to your access token in Cursor's environment.

Cursor sessions don't appear on the board yet.

Let Codex use the library

Add this to ~/.codex/config.toml, and set HUB_TOKEN to your access token in Codex's environment.

Codex sessions don't appear on the board yet.

Any MCP client

Point it at this address and send your access token as a Bearer token. Connectors on claude.ai and ChatGPT need OAuth, which the hub doesn't offer yet.

Your own scripts

Post to the board and library from anything. Use chatgpt, grok, cursor or codex as the source to get a named tab, or any other name to appear under Other.

GPT and Grok through Open WebUI

Add your OpenAI or xAI key to Open WebUI and connect it under Connections. Those chats then sync here automatically.

Import claude.ai export

On claude.ai open Settings → Privacy → Export data. Unzip the download and pick conversations.json and/or projects.json. Chats are archived with their full conversation; project knowledge files and instructions are stored as documents. Re-importing updates cards and keeps your edits.
